- quote_data: Quote data (empty response - may need market hours) ⚠️

- ohlc_data: OHLC data (needs correct format)

💡 FINDINGS:
-----------
1. Historical data fetching works perfectly
2. Market depth/order book is NOT available through standard REST API methods
3. Order book data likely requires:
   - WebSocket connection (not available in dhanhq library)
   - Different API endpoint
   - Market hours (quote_data returns empty when market closed)

🎯 RECOMMENDATION:
-----------------
For 20-level market depth data, you may need to:
1. Check Dhan API documentation for WebSocket endpoints
2. Use a different API provider for order book data
3. Use sample/simulated data for backtesting (current implementation)
